# Skyledger BR

Plataforma que usa dados abertos da ANAC para calcular risco de atraso de voos
e simular a exposição financeira de um benefício de reembolso por atraso.

## Desenvolvimento

- [Ambiente local (Docker Compose)](docs/ambiente-local.md)
- [Aplicação (build, execução, health-check, OpenAPI)](docs/aplicacao.md)
- [Ingestão dos dados da ANAC (VRA e aeródromos)](docs/ingestao.md)
- [Consulta de voos (API e tela de busca)](docs/consulta-voos.md)
